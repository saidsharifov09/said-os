# SAID OS

Личный органайзер, сделанный под человека с СДВГ: **записать мысль за 3–5 секунд и перестать держать дела в голове.**

Работает как приложение на iPhone и на Windows (PWA), без интернета, без аккаунтов и серверов. Все данные хранятся только на твоём устройстве.

## Что умеет
- **Быстрая запись** — кнопка «+» всегда под рукой: открыл, написал, Enter. Запись падает во «Входящие».
- **Входящие** — разбор в один тап: задача, событие, заметка или «посмотреть позже».
- **Мой день** — дата, часы, расписание по времени, три главных дела, задачи, просроченное, прогресс, ближайшие дни.
- **Задачи** — сроки, приоритеты, категории, подзадачи, повторы, фильтры, перенос.
- **Календарь** — свой, не Google: день, неделя, месяц.
- **Утренний обзор и вечерний отчёт** — с переносом недоделанного на завтра одной кнопкой.
- **Блокнот**, **«Посмотреть позже»**, **Цели**, **Привычки**, **История** (лента жизни), **Фокус** (одно дело + таймер).
- **Поиск** по всему. **Корзина** на 30 дней.
- **Резервные копии** в файл (по желанию с паролем) и перенос между iPhone и ноутбуком этим файлом.
- **Напоминания**: баннеры, пока приложение открыто, и кнопка «В Календарь iPhone» — чтобы iPhone напомнил сам. Честно о возможностях — в [docs/NOTIFICATIONS.md](docs/NOTIFICATIONS.md).

## Как устроено
Никаких сборщиков, npm и фреймворков: обычные файлы HTML, CSS и JavaScript. Что лежит в репозитории, то и работает.

```
index.html          — единственная страница
manifest.json       — описание приложения для установки (PWA)
sw.js               — service worker: работа без интернета
css/
  base.css          — цвета тем, каркас, навигация
  ui.css            — кнопки, поля, списки, всплывающие окна
  views.css         — оформление отдельных экранов
js/
  app.js            — запуск, навигация, каркас
  version.js        — номер версии
  core/             — ДАННЫЕ И ЛОГИКА (без интерфейса)
    db.js           — обёртка над IndexedDB
    store.js        — данные в памяти + сохранение, корзина
    schema.js       — версия схемы, миграции, стартовые разделы
    actions.js      — ВСЕ изменения данных (слой действий)
    selectors.js    — выборки: «задачи на сегодня», прогресс, серии привычек
    dates.js        — работа с датами
    parse-date.js   — распознавание «завтра», «в пятницу», «в 15:00»
    recur.js        — повторы
    search.js       — поиск
    backup.js       — копии, шифрование, файлы
    ics.js          — формат календаря .ics
    demo.js         — демо-данные
    ai-bridge.js    — заготовка под ИИ-ассистента
  ui/               — ОБЩИЕ ЭЛЕМЕНТЫ ИНТЕРФЕЙСА
    dom.js          — построение элементов, иконки
    sheet.js        — всплывающие окна, меню, подтверждения, тосты
    controls.js     — переключатели, чипы, выбор даты/цвета/повтора
    items.js        — строка задачи, строка события, кольцо прогресса
    capture.js      — быстрая запись
    reminders.js    — напоминания внутри приложения
    edit-*.js       — редакторы задачи, события, заметки, цели/привычки/истории
    ics-sheet.js    — окно «В Календарь iPhone»
    theme.js        — светлая / тёмная тема
  views/            — ЭКРАНЫ: по одному файлу на экран (today, tasks, calendar, …)
icons/              — иконки приложения
docs/               — документация (данные, уведомления, ИИ, виджет)
tests/              — автопроверки (не нужны для работы приложения)
```

Поток данных простой: **экран → действие (`actions.js`) → хранилище (`store.js`) → IndexedDB → экран перерисовывается.**

## Как менять через ИИ (вайб-кодинг)
Проект не привязан к конкретному ИИ — подойдёт любой, который умеет работать с репозиторием GitHub.

1. Дай ИИ доступ к репозиторию и попроси сначала прочитать `README.md`, `DECISIONS.md`, `ROADMAP.md`.
2. Опиши, что хочешь, простыми словами. Пример: «На экране "Мой день" добавь блок с цитатой дня под приветствием».
3. Напомни правила (можно скопировать):
   > Только чистый HTML/CSS/JS без сборки и без библиотек с CDN. Пути относительные. Интерфейс на русском. Данные менять только через `js/core/actions.js`. Новый файл — добавить в список `FILES` в `sw.js`. После изменений увеличить `VERSION` в `sw.js` и `APP_VERSION` в `js/version.js`. Если менялся формат данных — миграция в `js/core/schema.js` и описание в `docs/DATA.md`. Обновить `ROADMAP.md`.
4. Где что искать:
   - поменять **внешний вид** → `css/` (цвета — в начале `css/base.css`);
   - поменять **экран** → `js/views/<экран>.js`;
   - добавить **поле или новую сущность** → `js/core/actions.js` + `docs/DATA.md`;
   - **новый экран** → файл в `js/views/`, строчка в `ROUTES` в `js/app.js`, строчка в `sw.js`.
5. После слияния изменений в ветку `main` сайт обновится сам за 1–2 минуты. На устройстве новая версия появится со второго открытия приложения (или сразу: Настройки → «Обновить приложение»).

## Проверка (для разработчика или ИИ)
```
python3 -m http.server 8765      # запустить локально
node tests/unit.mjs              # логика дат, повторов, .ics
node tests/e2e.cjs               # сценарии в браузере (нужен Playwright)
```

## Приватность
- Данные не покидают устройство. Аналитики, трекеров и сторонних запросов нет.
- Репозиторий публичный, но в нём только код. Личных данных в коде нет; демо-данные выдуманные и загружаются только по кнопке.
- Геолокация не используется.
