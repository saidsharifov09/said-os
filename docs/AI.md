# ИИ-ассистент: что подготовлено

**Сейчас ИИ в приложении нет.** Сделана только основа, чтобы подключить его позже и безопасно.

## Принцип
1. ИИ **никогда не меняет данные сам**. Он может только *предложить* список действий.
2. Приложение показывает предложение человеку понятным текстом («Добавить задачу: …», «Перенести задачу: …»).
3. Действия выполняются **только после нажатия «Подтвердить»**.
4. Ключ API **не хранится в коде и в репозитории** (репозиторий публичный). Пользователь вводит ключ в настройках, он лежит только на устройстве (в `meta`) и не попадает в резервную копию.

## Что уже есть в коде
- `js/core/actions.js` — **слой действий**: единственный способ изменить данные (добавить, перенести, отметить, удалить…). Им пользуются все экраны.
- `js/core/ai-bridge.js` — «мостик» для ИИ:
  - `AI_ACTIONS` — белый список действий, которые ИИ разрешено предлагать (`task.add`, `task.move`, `task.complete`, `event.add`, `note.add`, `log.add`, …) с описанием параметров;
  - `AI_QUERIES` — чтение без подтверждения: `find` (поиск), `today` (дела на сегодня);
  - `describeActions()` — список действий в виде, готовом для передачи модели как «инструменты» (tools);
  - `previewProposal(calls)` — превращает предложение в человекочитаемые строки;
  - `applyProposal(calls, confirm)` — выполняет предложение, **обязательно** спросив человека через функцию `confirm`. Без неё бросает ошибку.

Формат предложения от ИИ:
```json
[
  { "action": "task.add", "params": { "title": "Купить билеты", "date": "2026-11-20", "time": "18:00" } },
  { "action": "task.move", "params": { "id": "abc123", "date": "2026-11-21" } }
]
```

## Как подключить (план для будущей работы)
1. **Экран чата** `js/views/assistant.js` + пункт в навигации (`js/app.js`).
2. **Настройка ключа**: поле в `js/views/settings.js`, хранить в `meta.aiKey`; добавить `aiKey` в список `LOCAL_META` в `js/core/backup.js`, чтобы ключ не уходил в копии.
3. **Запрос к модели** прямо из браузера (`fetch` к API выбранного провайдера). В запрос передавать: `describeActions()` как инструменты, результат `AI_QUERIES.today()` как контекст и сообщение пользователя. Запрашивать ответ в виде массива вызовов (tool use / JSON).
4. **Показ предложения**: `previewProposal(calls)` → окно со списком → кнопки «Подтвердить» / «Отмена» (`confirmSheet` из `js/ui/sheet.js`) → `applyProposal(calls, confirm)`.
5. В `sw.js` запросы к чужим адресам уже не кэшируются — менять ничего не нужно.

## О чём помнить
- Запрос к ИИ отправляет часть данных (текст задач) стороннему сервису. Об этом нужно явно предупредить на экране и отправлять минимум.
- Вызов API прямо из браузера раскрывает ключ на устройстве пользователя — для личного приложения это приемлемо, но ключу стоит задать лимит расходов.
- Проект не привязан к одному провайдеру: мостик описывает действия нейтрально.
