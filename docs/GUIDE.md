# SAID OS: установка и инструкция на 5 минут

Всё делается через сайт GitHub и сам iPhone — без командной строки.

## 1. Включить сайт (GitHub Pages) — один раз
1. Открой в Safari `github.com`, войди в аккаунт и зайди в репозиторий **said-os**.
2. Нажми **Settings** (шестерёнка; на телефоне — в меню «⋯» или в полосе вкладок, которую можно прокрутить вправо).
3. В левом меню выбери **Pages**.
4. В блоке **Build and deployment**: Source — **Deploy from a branch**; Branch — **main**, папка **/ (root)** → **Save**.
5. Подожди 1–2 минуты и обнови страницу. Сверху появится адрес вида
   `https://ТВОЙ-ЛОГИН.github.io/said-os/` — это и есть приложение.

Если пункта Settings не видно в приложении GitHub — открой репозиторий в Safari и включи «Версию для компьютера» (кнопка «аА» в адресной строке → «Запрос настольного веб-сайта»).

## 2. Установить на iPhone
1. Открой адрес приложения **в Safari** (именно в Safari, не в Chrome).
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран "Домой"»** → **Добавить**.
4. На экране появится иконка SAID OS. Открывай приложение **только с неё** — тогда оно работает на весь экран, без интернета, и iPhone не удаляет его данные.
5. Перетащи иконку в Dock (нижний ряд), чтобы она всегда была под пальцем.

Важно: данные Safari и данные приложения с иконки на iPhone хранятся **раздельно**. Начни пользоваться сразу с иконки.

## 3. Установить на Windows
1. Открой адрес в **Chrome** или **Edge**.
2. В адресной строке справа нажми значок установки (монитор со стрелкой) → **«Установить»**.
   Или меню «⋮» → «Транслировать, сохранить и поделиться» → **«Установить страницу как приложение»** (в Edge: «⋯» → «Приложения» → «Установить этот сайт как приложение»).
3. SAID OS появится в меню «Пуск» и откроется в отдельном окне.

## 4. Инструкция на 5 минут

**Главное правило: мысль появилась — сразу в «+».** Не думай, куда её положить. Разберёшь потом.

1. **Записать (3 секунды).** Нажми большую синюю кнопку **«+»** внизу → напиши → **Enter**. Всё, запись во «Входящих».
   - Напишешь «завтра», «в пятницу», «через неделю», «в 15:00» — появится голубая подсказка с датой. Не нужна — нажми на неё, и она исчезнет.
   - «Несколько подряд» — окно не закрывается после Enter: удобно выгрузить из головы сразу всё.
   - На ноутбуке: клавиша **N** (или Ctrl+K) — быстрая запись, **/** — поиск.

2. **Разобрать (один тап на запись).** Значок лотка вверху → у каждой записи четыре кнопки: **Задача · Событие · Заметка · Позже**. Нажал — запись на месте. Ошибся — «Изменить» во всплывающей плашке.

3. **Утро: «Мой день».** Открой приложение — увидишь дату, расписание, задачи и просроченное. До полудня сверху будет карточка **«Утренний обзор»**: перенеси хвосты, выбери звёздочкой до трёх главных дел, нажми «Начать день».

4. **Днём.** Сделал — нажми на кружок слева от задачи. Не успеваешь — стрелка справа → «Завтра». Не знаешь, за что взяться — **«С чего начать?»**: приложение покажет одно дело и таймер на 5, 15 или 25 минут.

5. **Вечер.** После 18:00 появится карточка **«Вечерний отчёт»**: что сделано, что нет, и одна кнопка **«Перенести всё на завтра»**.

6. **Чтобы iPhone напомнил сам.** Открой задачу или событие → **«В Календарь iPhone»** → «Добавить». Напоминание придёт от системного Календаря, даже если SAID OS закрыт. (Баннеры самого SAID OS работают, только пока он открыт.)

7. **Раз в неделю — копия.** «Ещё» → «Настройки и копии» → **«Сохранить копию»** → отправь файл себе в Telegram («Избранное») или в «Файлы». Приложение само мягко напомнит. Данные живут только на устройстве — копия их единственная страховка.

## 5. Перенос между iPhone и ноутбуком
Это **не синхронизация**, а перенос файлом:
1. На первом устройстве: Настройки → (по желанию пароль) → **«Сохранить копию»** → отправь файл себе: Telegram «Избранное», почта или iCloud Drive (на Windows — через `icloud.com` в браузере).
2. На втором устройстве: скачай файл → Настройки → **«Импорт из файла копии»** → выбери файл.
3. Выбери **«Объединить»** (безопасно: ничего не удаляется, из двух версий одной записи остаётся более свежая) или **«Заменить всё»** (второе устройство станет точной копией первого; приложение предупредит).

Совет: выбери одно «главное» устройство (iPhone), а ноутбук обновляй из копии, когда садишься за большую работу.

## 6. Как принять изменения (смёржить Pull Request) с iPhone
1. Открой репозиторий на `github.com` или в приложении GitHub → вкладка **Pull requests**.
2. Открой нужный запрос → прокрути вниз → зелёная кнопка **Merge pull request** → **Confirm merge**.
3. Через 1–2 минуты сайт обновится. В приложении: Настройки → **«Обновить приложение»** (или просто открой его дважды).

## Если что-то пошло не так
- **Приложение не обновилось** → Настройки → «Обновить приложение».
- **Случайно удалил** → «Ещё» → «Корзина» → «Вернуть» (хранится 30 дней).
- **Пропали данные на iPhone** → скорее всего, открыто в Safari, а не с иконки (у них разные хранилища). Открой с иконки. Если данных нет и там — импортируй последнюю копию.
- **Хочу посмотреть, как всё выглядит с данными** → Настройки → «Загрузить демо-данные» (удаляются одной кнопкой).
